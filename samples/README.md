# Localhost Loader samples

- `Hello-Local-App.zip`: a static web app. No runtime pack required.
- `Python-Local-Server.zip`: Python 3.13 server using only the standard library.
- `Node-Local-Server.zip`: Node.js 18.20.4 server using only built-in modules. Requires the Node mobile native library in the APK.

Import each ZIP separately from the Apps page. Executable Python/Node packages require an explicit trust confirmation.
