BUILD ENVIRONMENT LIMITATION
----------------------------
This container does not have the Android SDK, Android Build Tools, NDK, AAPT2,
D8/R8, or a local Gradle installation. Therefore no APK was compiled or signed
in this session. This archive contains the Android Gradle source project and a
GitHub Actions workflow which fetches the Node mobile runtime and builds a
Debug APK for arm64-v8a and x86_64.

NEXT BUILD ACTION
-----------------
Open the project in Android Studio or push it to GitHub and run:
    .github/workflows/android-build.yml

The CI artifact is a Debug APK for sideload testing, not a Play Store-certified
release. Verify Node native library compatibility, including Android 16 KB page
size requirements, before a public store release.
